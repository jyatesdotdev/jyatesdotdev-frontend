# components/ — UI components

## Conventions

- One component per file, kebab-case filenames, **co-located tests**
  (`likes.tsx` + `likes.test.tsx`). Tests use Vitest + Testing Library and wrap
  router-dependent components in `<MemoryRouter>`.
- Styling is inline Tailwind utility classes with `dark:` variants. No CSS modules,
  no styled-components. Dark mode is a `dark` class on `<html>` set by `theme-provider.tsx`
  (persisted to localStorage key `jyates-theme`).
- Navigation uses `react-router-dom` (`<Link>`, `useParams`, `useLocation`).
- Data fetching uses SWR against `../api/`.

## Load-bearing components

- `seo.tsx` — meta/OG/Twitter/canonical tags as plain `<title>`/`<meta>`/`<link>`
  elements (React 19 hoists them into `<head>`, including during prerendering — no
  Helmet); every page renders it.
- `analytics.tsx` — RUM abstraction: loads real `aws-rum-web` when
  `VITE_RUM_APPLICATION_ID` is set, otherwise a `LocalRum` mock that POSTs to the dev
  `/rum-telemetry` endpoint. Exposes `window.awsRum`. E2E telemetry tests in the
  integration repo assert on these beacons — changing event names/shapes breaks them.
- `mdx.tsx` — the `MDXComponents` map for blog posts: heading anchors, `CustomLink`,
  sugar-high `Code`, `PlantUML`. In prod, PlantUML diagrams are prebuilt SVGs served
  from `/diagrams/<hash>.svg` (generated by `scripts/generate-diagrams.js` during
  `npm run build`); only dev fetches from public plantuml.com (its URL is in the CSP
  in the infra repo). Authoring syntax in MDX: `<PlantUML>{`` `@startuml ... @enduml` ``}</PlantUML>`.
- `post/likes.tsx`, `post/comments.tsx` — interactive widgets; they send an
  `X-Visitor-Id` header the backend requires, and the comment form has a honeypot
  `website` field. E2E tests select by emoji text (`🤍`/`❤️`), form `name` attributes,
  and Tailwind classes — **changing button text/markup here breaks
  `jyatesdotdev-integration` specs.**
- `contact.tsx` — submits via its own fetch with a hidden honeypot `website` input;
  there is no reCAPTCHA anywhere in the app.
